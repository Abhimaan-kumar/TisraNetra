# TFLite Models

## MobileFaceNet Model

This directory should contain the MobileFaceNet TFLite model file.

### Download Instructions

1. Download the model from:
   ```
   https://github.com/sirius-ai/MobileFaceNet_TF/raw/master/output_models/MobileFaceNet.tflite
   ```

2. Save it as: `mobile_face_net.tflite`

3. The file should be ~112 KB (MobileFaceNet.tflite)

### Alternative Download

You can also download from:
- GitHub: https://github.com/sirius-ai/MobileFaceNet_TF/releases
- Look for the `MobileFaceNet.tflite` file in the output_models folder

### Verification

After downloading, the file structure should be:
```
assets/
└── models/
    └── mobile_face_net.tflite
```

The model is used for face embedding generation in the person identification feature.
